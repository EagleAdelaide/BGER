# Data access

No image data are included in this archive.

**CUB-200-2011.** Available from the Caltech Vision Lab dataset page (Wah et
al., 2011). Place the extracted `CUB_200_2011/` directory under
`cub_training/data/`. The split used (4,794 / 600 / 600 from the official
training pool; official 5,794-image test set) is regenerated by the training
script; its SHA256 is recorded in `cub/data/cub_ev_r101_rows.csv`.

**OSLD** (Bastan et al., arXiv:1911.07440). The official repository
github.com/mubastan/osld links the release (`osld.zip`). License: CC BY-NC 4.0;
"The individual logos and images are owned by their respective rights owners";
"The dataset can be used only for research purposes." No OSLD image or derived
image is distributed here. The results contain per-query records of model
outputs keyed by release file names and logo identities (rankings, scores,
localization hit bits, energy fractions, 7x7 numeric maps), but no pixels;
box coordinates appear only for the four numeric-map example queries (appendix figure); recomputing localization-dependent analyses requires your
own copy of the release, checked by `logo_retrieval_osld/code/osld_release_check.py`
(identity-disjoint splits, file integrity, exact duplicates, box validity,
coordinate convention; the records digest of the release used is
`cd19f0f24960acf19a0c23ed33975e288d6c2fcc31cfd9eb8af49c7d9f65bf7f`).
