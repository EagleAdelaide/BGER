# Saved-record reproduction collection

The current entry point is the repository-root README_REPRODUCE.md and
reproduce/run_cpu_checks.py. OSLD code/records are in logo_retrieval_osld/,
the exploratory derived OpenLogo study is in openlogo/, and related CUB
classification evidence is in cub/ with its matched implementation in cub_training/.
EXPANDED_TABLES.pdf is repository supporting material, not extra manuscript pages
or a separately uploaded OpenReview attachment.

The historical source requirements describe the original runs; current CPU
requirements are in reproduce/ at the repository root. Original numerical records,
pre-test definitions and scientific hashes are retained. The current release
manifest binds export bytes; historical hashes identify their internal originals.
One resource-ledger derivative removes scheduler job identifiers while preserving
all recorded reservation and elapsed-time numbers, with explicit hash bindings.

No licensed images, weight/checkpoint binaries, embeddings or OpenLogo raw neural
shards are supplied. Missing annotation/raw-output/checkpoint layers are SKIP;
saved-record checks are not fresh model inference or training. Required external
data access and attribution are described in DATA_ACCESS.md and the root rights
document. OpenLogo's official coordinate semantics remain UNVERIFIED.
